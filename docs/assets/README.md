# MemKernel visual identity

The mark is an **M made from folded, overlapping pages**: a reference to stored
project context. Copper is the accent; charcoal and ivory provide contrast.

- [Logo](memkernel-logo.webp): 512 × 512, copper on ivory.
- [README banner](memkernel-banner.webp): 1600 × 533, copper and ivory on charcoal.

Keep the mark's proportions and clear space. Use the banner with descriptive alt
text and keep essential setup instructions as real text in the README.
